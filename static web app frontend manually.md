
If your React app is inside a folder named frontend, this is the clean manual flow for Azure Static Web Apps: create the resource, get the deployment token, build the app, then deploy the built output. Azure supports manual deployment with a deployment token and swa deploy. 1 2 3
Bash# Code Generated by Sidekick is for learning and experimentation purposes only.
npm install -g @azure/static-web-apps-cli
az login
az group create --name my-swa-rg --location eastus
az staticwebapp create --name my-react-swa --resource-group my-swa-rg --location eastus --sku Free

Then get the deployment token. Keep it secret and do not commit it to source control. 1 3
Bash# Code Generated by Sidekick is for learning and experimentation purposes only.
az staticwebapp secrets list --name my-react-swa --resource-group my-swa-rg --query "properties.apiKey" -o tsv

Build your React app from the frontend folder. The build output is usually build for CRA or dist for some setups. 1 3
Bash# Code Generated by Sidekick is for learning and experimentation purposes only.
cd frontend
npm install
npm run build

If your output folder is build, deploy with:
Bash# Code Generated by Sidekick is for learning and experimentation purposes only.
swa deploy --output-location build --deployment-token "<YOUR_DEPLOYMENT_TOKEN>"

If your output folder is dist, deploy with:
Bash# Code Generated by Sidekick is for learning and experimentation purposes only.
swa deploy --output-location dist --deployment-token "<YOUR_DEPLOYMENT_TOKEN>"

A better repeatable option is to store the token in an environment variable and redeploy after each new build. 3
Bash# Code Generated by Sidekick is for learning and experimentation purposes only.
export SWA_CLI_DEPLOYMENT_TOKEN="<YOUR_DEPLOYMENT_TOKEN>"
swa deploy --output-location build

If you are on Windows PowerShell:
PowerShell# Code Generated by Sidekick is for learning and experimentation purposes only.
$env:SWA_CLI_DEPLOYMENT_TOKEN="<YOUR_DEPLOYMENT_TOKEN>"
swa deploy --output-location build

Practical recommendation: run npm run build in frontend, confirm whether the output folder is build or dist, then use that exact folder in swa deploy. If you want, I can give you the exact commands for Vite React, CRA, or add React Router refresh handling next. 2 1
